# BlockCraft

Майнкрафт-подобная игра для телефона (Godot 4.3, GDScript).

## Мир
Бесконечный, генерируется по мере движения (фоновые потоки):
океаны, реки, пляжи, горы со снежными вершинами, биомы
(равнины, лес, пустыня, снежная тайга), пещеры, руды (уголь, железо,
золото, алмазы) на разной глубине, бедрок, деревья, ели, кактусы.
Дальность прорисовки: константа `RD` в `scripts/world.gd`.

## Сборка APK
1. Залей все файлы проекта в репозиторий GitHub (ветка main).
2. Actions -> Build Android APK -> дождись зелёной галочки.
3. В разделе Artifacts скачай BlockCraft-apk.

## Управление
- Левая часть экрана: плавающий джойстик.
- Правая часть: свайп - камера; короткий тап - поставить блок; удержание - ломать.
- Кнопка со стрелкой - прыжок (в воде - плыть вверх).
- Нижняя панель - выбор блока.
- Кнопка II справа сверху (или «назад») - пауза и настройки.
- Изменения мира сохраняются автоматически.

## Текстуры
Атлас `textures/atlas.bytes` (PNG внутри) (плитки 128x128): земля, кора дуба и ели, листья дуба и ели, вода, трава (сделана из листьев).
Остальные блоки пока цветные.
